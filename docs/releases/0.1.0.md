ToolPermit is a Kotlin approval broker for agent tool calls. Policies allow, deny, or hold an invocation for local operator review before it reaches a configured HTTP tool.

This release includes JSON argument constraints, SQLite persistence, fingerprint-bound approvals, expiry, audit exports, and durable execution claims. Repeated IDs reuse stored outcomes. Timeouts and interrupted calls are not automatically replayed.

Download `toolpermit-0.1.0.zip`, extract it, and run `bin/toolpermit demo --out results/demo` (`bin\toolpermit.bat` on Windows). Java 21 or later is required. The demo starts local HTTP tools, holds a file write for scripted approval, and verifies that resubmission does not repeat the write. No model key is needed.

The service is loopback-only and designed for one trust domain. Keep its database and operator commands outside the agent's permissions. It does not provide MCP transport, multi-tenant authentication, or exactly-once remote side effects. See the repository documentation for integration and recovery rules.
